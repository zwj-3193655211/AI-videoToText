# 实时语音识别系统

## 项目简介

实时识别部分，该部分是一个基于Python的实时语音识别系统，能够实时捕获系统音频并进行语音识别，支持字幕显示和实时翻译功能。该系统使用SenseVoice模型进行语音识别，并提供了友好的图形用户界面。

## 主要功能

- 实时系统音频捕获
- 实时语音识别
- 可调节的字幕显示窗口
- 实时翻译功能
- 字幕窗口透明度调节
- 字体大小自定义
- 缓冲区大小调整
- 字幕位置自由拖动
- 字幕窗口大小调整

## 系统要求

- Python 3.7+
- Windows 10/11
- 支持的系统音频设备

## 依赖包

```
PySide6
soundcard
soundfile
numpy
torch
funasr
```

## 安装说明

1. 克隆项目到本地

2. 安装所需依赖：
   
   ```bash
   pip install -r requirements.txt
   ```

3. 确保已下载SenseVoice模型文件并放置在正确位置

## 使用说明

1. 运行主程序：
   
   ```bash
   python 实时识别.py
   ```

2. 主界面功能：
   
   - 开始/停止按钮：控制语音识别
   - 语言选择：选择识别语言
   - 翻译开关：启用/禁用实时翻译
   - 字幕设置：调整字幕显示参数

3. 字幕窗口操作：
   
   - 拖动：点击并拖动窗口任意位置
   - 调整大小：拖动窗口边缘
   - 设置：点击设置按钮调整透明度、字体大小等
   - 关闭：点击关闭按钮

## 文件结构

- `实时识别.py`: 主程序文件
- `subtitle.py`: 字幕窗口实现
- `translate_subtitle.py`: 翻译字幕窗口实现
- `settings_manager.py`: 设置管理模块
- `translator.py`: 翻译功能实现
- `subtitle.ui`: 字幕窗口UI文件
- `translate_subtitle.ui`: 翻译字幕窗口UI文件
- `subtitle_settings.json`: 字幕设置配置文件

## 注意事项

1. 首次运行需要下载语音识别模型
2. 确保系统音频设备正常工作
3. 建议使用耳机或外接音箱以获得更好的识别效果
4. 翻译功能需要网络连接

## 常见问题

1. 如果遇到音频捕获问题，请检查系统音频设备设置
2. 如果识别效果不理想，可以尝试调整缓冲区大小
3. 如果翻译功能无法使用，请检查网络连接
